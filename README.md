# SkyproWallet

Учебный командный проект по разработке веб-приложения для управления финансами.

## Стек

- React
- Vite
- React Router
- Axios
- ESLint + Prettier

## Установка

```bash
git clone <repo-url(ssh)>

npm install
```

## Запуск

```bash
npm run dev
```

## Проверка кода

```bash
npm run lint
npm run format
```
