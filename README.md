# SkyproWallet

Веб-приложение для учёта личных расходов: регистрация и вход, список транзакций с добавлением и удалением, аналитика по категориям за выбранный период.

## Технологии

- React 19, Vite 7
- React Router 7
- styled-components
- Axios
- react-calendar, date-fns
- Recharts
- react-toastify

## Установка

```bash
git clone <url-репозитория>
cd skypro-wallet
npm install
```

## Запуск

```bash
npm run dev
```

Сборка и предпросмотр продакшен-сборки:

```bash
npm run build
npm run preview
```

## Проверка кода

```bash
npm run lint
npm run format
```

## Основные возможности

- Регистрация и авторизация с валидацией полей и сообщениями об ошибках
- Главная страница: таблица расходов, форма добавления транзакции, удаление записи с подтверждением
- Страница аналитики: диаграмма по категориям, сумма за период, календарь выбора периода (на десктопе), отдельный экран календаря на узких экранах
- Выход из аккаунта с очисткой данных сессии и переходом на страницу входа
